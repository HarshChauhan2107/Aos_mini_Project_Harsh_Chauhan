Scheduling policies
FCFS, SJF, SRTF, Priority (1 = highest), Round Robin, and non-preemptive EDF.

Before academic submission
1. Fill in your name, roll number, class, college, and instructor details in the report.
2. Create your own GitHub repository, upload this project, and paste its URL in the report.
3. Run the application on your own computer and capture fresh screenshots if required by your institution.

Windows requirement
Install a MinGW-w64 GCC compiler (MSYS2 UCRT64 is documented in README.md), then run run.bat.
The Windows executable is compiled locally by the script; no incompatible prebuilt Linux binary is included.
