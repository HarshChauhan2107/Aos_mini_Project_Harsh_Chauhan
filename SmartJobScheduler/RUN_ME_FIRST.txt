SMART JOB SCHEDULER - START HERE
================================

WHAT YOU NEED
- Windows 10 or Windows 11
- MinGW-w64 GCC installed and available in PATH
- A modern browser (Edge, Chrome, or Firefox)

START THE PROJECT
1. Extract the downloaded ZIP to a folder. Do not run from inside the ZIP file.
2. Install MSYS2 from https://www.msys2.org.
3. Open the MSYS2 UCRT64 terminal from the Start menu and run: pacman -S mingw-w64-ucrt-x86_64-gcc
4. Add C:\msys64\ucrt64\bin to the Windows PATH (use your actual MSYS2 folder if you chose a different install location).
5. Open a NEW Command Prompt and type: gcc --version
6. Double-click run.bat.
7. Wait for the message that the server is running at http://localhost:8080.
8. Your browser should open automatically. If not, type http://localhost:8080 in the address bar.
9. Keep the black Command Prompt window open while using the dashboard.
10. To stop, click the Command Prompt window and press Ctrl+C.

PORT 8080 ALREADY IN USE?
Double-click run_8081.bat and visit http://localhost:8081.

WHAT TO TRY IN THE DASHBOARD
- Run FCFS, SJF, SRTF, Priority, Round Robin, and EDF.
- Add a new task in the Add a Job panel.
- Delete a task using the small x in its row.
- Click Smart Recommend.
- Click Compare all algorithms in Benchmark Lab.
- Restore demo data when you want the original seven tasks back.

WHERE YOUR DATA IS SAVED
Your job queue is saved in data\jobs.csv. Changes remain after restarting the server.

IMPORTANT
- Do not close the black server window while you are using the website.
- Do not move or rename the web, src, or data folders after extracting the ZIP.
- Read README.md for complete instructions and troubleshooting.
- The report's GitHub URL is intentionally blank for your own repository link.
