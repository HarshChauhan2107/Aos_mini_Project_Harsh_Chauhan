DISKSCOPE - WINDOWS QUICK START
================================

IMPORTANT: Extract the ENTIRE ZIP first. Do not run the program from inside
File Explorer's compressed-ZIP preview, and do not move individual files.

1. Extract intelligent-disk-io-analyzer.zip using right-click > Extract All.
2. Open the extracted intelligent-disk-io-analyzer folder.
3. Confirm that you can see these items:
      build.bat
      run.bat
      src\server.c
      web\index.html
      web\style.css
      web\app.js
4. Install MinGW-w64 GCC if it is not already installed. The gcc command
   must be available in Command Prompt (PATH).
5. Double-click build.bat. It should say that disk_analyzer.exe was created.
6. Double-click run.bat.
7. Keep the black Command Prompt window open.
8. Open Chrome or Edge and visit:
      http://127.0.0.1:8080

If build.bat says "GCC was not found":
- Install MinGW-w64 (GCC).
- Add the MinGW-w64\bin folder to the Windows PATH environment variable.
- Close and reopen Command Prompt, then run: gcc --version
- Run build.bat again.

If the browser says it cannot connect:
- Make sure run.bat is still running and has not been closed.
- Try http://127.0.0.1:8080/api/health
- If port 8080 is busy, open Command Prompt in the project folder and run:
      disk_analyzer.exe 8090
  Then visit http://127.0.0.1:8090

If you still cannot run it, send a screenshot of the COMPLETE error shown
in the black Command Prompt window, and mention which step failed.
